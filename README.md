# cpp-raylib-simple-collision-game

## Overview
This is my first project using Raylib with pure C++. Through this project, I learned about:
- Overlapping and collision detection.
- Handling object edges.
- Effective use of structs and vectors.

## Features
- Player and enemy objects with collision detection.
- Dynamic spawning of enemies.
- Game over state when a collision occurs.

## Future Improvements
- Adding delays for the game over screen and other events.
- Implementing timers for enhanced gameplay mechanics.

## Build and Run Instructions

### Prerequisites
- [Raylib](https://www.raylib.com/) installed on your system.
- A C++ compiler (e.g., MinGW for Windows).

### Steps
1. Clone this repository to your local machine.
2. Open the project folder in Visual Studio Code.
3. Use the provided `Makefile` to build the project:
   - For a debug build, run the `build debug` task.
   - For a release build, run the `build release` task.
4. Run the generated executable (`main.exe`) to play the game.

Enjoy the game and feel free to contribute or suggest improvements!
